# Виртуальная примерочная — этап 2

Процедурный прототип на Python 3.10+ и Pillow 12.3.0. Создаёт плоский визуальный эскиз одежды на изображении человека. Два плечевых ориентира на каждом изображении задаются вручную. Размер одежды, комфорт и свойства ткани не вычисляются. Учебные изображения нарисованы программно; это не фотографии людей и не результаты пользовательского исследования.

## Запуск

Из каталога проекта:

```sh
python -m venv .venv
# macOS / Linux:
source .venv/bin/activate
# Windows PowerShell: .venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python make_examples.py
python fitting.py examples/straight.json results/local_straight
python fitting.py examples/tilted.json results/local_tilted
python -m tests.test_fitting
```

Первые два запуска создают `preview.png` и `result.json` с параметрами преобразования и предупреждением. Тестовый запуск должен завершиться строкой `RESULT: 12/12 passed`. Проверка ошибки:

```sh
python fitting.py examples/invalid.json results/local_invalid
```

Ожидаются код завершения 2 и `ERROR: SPAN: ...`; новый каталог результата не создаётся. Проверенный журнал включён в `results/verification.json`. Готовые примеры находятся в `results/straight` и `results/tilted`.

## Свои данные

Скопируйте один из JSON-примеров. Укажите пути к фото человека (JPEG/PNG) и изображению одежды с прозрачным фоном (PNG). Пути считаются от каталога JSON. Все изображения ограничены 12 млн пикселей. Координаты задаются в пикселях после применения EXIF Orientation: начало в левом верхнем углу, x вправо, y вниз. Пары точек идут слева направо на экране; расстояние между ними не меньше 2 px. Масштаб ограничен диапазоном 0.1–10. Для прототипа подходят фронтальные изображения верхней одежды без перекрытия руками. Фон у одежды подготавливается заранее, автоматически он не удаляется.

Выходной каталог предназначен для одной попытки; повторный запуск с тем же каталогом заменяет два файла результата. При новой попытке выбирайте новый каталог. Обработка локальная, сетевых запросов в коде нет. Исходные фото не копируются в каталог результатов; пользователь управляет их хранением. Графический интерфейс и база данных пока не реализованы. Логическая модель данных находится в отчёте; в этой версии параметры читаются из JSON.

## Файлы и алгоритмы

- `fitting.py`: A1 — `load_image`, `validate_anchors`; A2 — `similarity`, `compose`; `run` связывает обработку и запись файлов.
- `make_examples.py`: воспроизводимое создание собственных тестовых изображений и параметров.
- `tests/test_fitting.py`: 12 функций с независимыми ожидаемыми значениями; стандартный Python, без pytest.
- `results/verification.json`: фактические команды, коды завершения и вывод проверки.

## Git

Локальная история проекта хранится в `.git`. Публичный репозиторий не создавался. Для переносимой версии в комплекте поставки есть `virtual_fitting_history.bundle`. Восстановление истории из каталога, куда распакован комплект:

```sh
git clone virtual_fitting_history.bundle restored_project
cd restored_project
git log --oneline
```

## Проверенная среда

Python и Pillow из среды подготовки отчёта; точные версии записаны в `results/environment.json`. Воспроизведение требует установленного Python и установки единственной зависимости из `requirements.txt`.
